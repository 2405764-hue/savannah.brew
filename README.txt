SAVANNA BREW CAFE — HTML & CSS ASSIGNMENT SOLUTION

PROJECT FILES
index.html is the home page; about.html is the story and values page; menu.html contains the café menu; gallery.html is the responsive photo gallery; contact.html contains the booking request form and opening-hours table. Shared styling is in css/style.css, and the local photos and custom logo are in images/.

HOW TO OPEN
Extract the project folder and open index.html in a browser. Use the navigation to visit all five pages.

IMPLEMENTATION NOTES
The site uses semantic HTML5, one external stylesheet, CSS variables, Flexbox, CSS Grid, responsive breakpoints, accessible focus states and image alternative text. The reservation form uses native browser validation, but it is a static HTML/CSS demo and does not submit bookings to a server. Google Fonts are optional; Georgia and Arial fallbacks are defined.

VALIDATION
All five HTML pages were checked with the W3C Nu HTML Checker: zero errors and zero warnings. The stylesheet was parsed locally with tinycss2: zero parse errors. The W3C CSS Validator service returned a server-side error during this run, so CSS validation through that service remains to be repeated when it is available.

IMAGES
Local café photographs were selected from Unsplash image-search results. Photographer details were not included with the provided assignment materials; independently verify image credits/licensing before public or commercial reuse. Images are stored locally so the gallery does not depend on remote image hosting.
